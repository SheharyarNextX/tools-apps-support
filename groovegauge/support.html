Support

Help with profiles, listening sessions, care history, personal service targets, reminders and portable backups.

Quick start

  1. Create a cartridge or stylus profile. Add any starting hours you already know.
  2. Start and stop the listening timer, or add a session manually.
  3. Record cleaning, inspection, alignment, replacement or another care event.
  4. Review the profile’s hours and history, then set personal cleaning, inspection or replacement targets if useful.

Hours and service targets

GrooveGauge totals the starting hours and saved listening sessions for each profile. Cleaning, inspection and replacement targets are reminder values you choose; they do not measure wear, diagnose stylus condition or replace the cartridge maker’s guidance.

Optional local reminder

Choose a reminder hour in Settings if you want a local care check. GrooveGauge schedules a notification only when at least one care item is due or due soon, and asks for permission only when a notification needs to be scheduled. The reminder stays on your device, and declining permission leaves every other feature available.

Export and restore

Use Settings to export a CSV for a portable history or JSON for a restorable GrooveGauge backup. Exported files leave the app only through the destination you select. Restore accepts a validated GrooveGauge JSON backup and replaces local app records only after the in-app confirmation.

Keep a recent JSON backup before changing devices or clearing app storage.

Ads and consent

Consent choices are requested where required before Google Mobile Ads starts. If ads cannot be requested, all profiles, timers, manual sessions, care logs, reminders, search and exports remain available. The rewarded ad is optional and changes only a temporary cosmetic card style.

Troubleshooting

  • If a timer total looks wrong, check that the session was stopped and saved to the intended profile.
  • If a reminder does not appear, confirm notification permission is enabled for GrooveGauge in device settings.
  • If restore is rejected, select an unedited JSON backup exported by GrooveGauge.
  • If an export destination is unavailable, check that a compatible Files or sharing destination is installed and enabled.

Safe equipment care

Switch off and secure the turntable before handling a stylus or cartridge. Follow the manufacturer’s cleaning, inspection, alignment and replacement instructions. GrooveGauge is a recordkeeping tool, not a condition assessment.
